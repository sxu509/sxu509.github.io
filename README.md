# Su Xu's academic website

Site URL: https://sxu509.github.io

Built with [Academic Pages](https://github.com/academicpages/academicpages.github.io).

## Updating the site

- `_pages/about.md`: biography and contact information
- `_pages/research.md`: publications, preprints, and manuscripts in preparation
- `_pages/teaching.md`: courses and teaching experience
- `_pages/personal.md`: personal page and photos of PP and Bobby
- `_config.yml`: profile and site settings
- `_data/navigation.yml`: navigation links

GitHub Pages builds and publishes the `main` branch from the repository root.
Changes pushed to `main` are published automatically.

To preview locally, install Ruby and Bundler, then run `bundle install` and
`bundle exec jekyll serve`.

## Content sources

Biography, research, and teaching experience are based on Su Xu's supplied CV.
Course titles, personal text, and the portrait come from the
[previous website](https://sites.google.com/view/su-xu).
The Personal page uses the supplied `pp.png` and `Bobby.png` photographs.

The four DOI-linked papers were checked on 2026-09-28 against Oxford Academic,
AIMS Press, Crossref, and the bioRxiv API. Preprints are listed separately from
peer-reviewed articles. Manuscripts in preparation follow the supplied CV.
